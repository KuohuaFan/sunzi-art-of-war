# 《孫子兵法》內容編輯說明

本站正文鎖定維基文庫固定修訂版 `oldid=7906064`，原始維基文字保存在 `content/source/sunzi-wikisource-oldid-7906064.wiki`。正文僅取十三篇，來源頁所附〈答話〉不混入正文。

篇旨今譯、要義提點、概念標籤及異文說明集中在 `scripts/build_sunzi_data.py` 的 `EDITING` 物件。修改後執行：

```bash
python3 scripts/build_sunzi_data.py
pnpm check
pnpm test
```

程式會自動更新 `shared/sunzi-data.ts`，並重新計算篇數、段數與字數。正文段號採 `篇次-段次`，例如 `03-08`，已發布後不應任意重排；若必須調整，應同步檢查要義提點與 AI 引用。

維基文庫頁面文字依 CC BY-SA 4.0 提供。本站在介面中保留來源固定連結與授權標示；篇旨今譯與要義提點為本站自撰。

## 多語靜態版本

英文、日文、韓文、西班牙文、法文及德文的可索引版本由 `scripts/generate-static-translations.ts` 使用 `gpt-5-mini` 產生，來源固定為 `shared/sunzi-data.ts`。執行：

```bash
pnpm content:i18n
pnpm check
pnpm test
```

原始結構化輸出保存在 `content/generated/sunzi-translations.json`，網站使用的型別化資料保存在 `shared/sunzi-translations.ts`。產生器可續跑，並以四個工作者有限併發處理缺少的篇章；每篇最多重試四次。

自動品質閘門要求：每語言恰有十三篇；每篇段號、順序與要義 `segmentId` 必須逐項等於固定繁中底本；所有欄位不得空白；SEO 描述必須為 50–160 個 Unicode 字元；西文不得殘留大量未翻譯漢字。發布前仍須抽查各語首篇、中篇與末篇。翻譯屬 AI 輔助讀本，不取代中文原典；頁面必須保留固定版本、段號、原文對照與警語。

## 字數與預估閱讀時間

章節統計只計入原文或該語譯文的段落文字，不納入篇名、摘要、要義、標籤及原文對照。繁體中文與日文以不含空白的可見字元計數；英文、韓文、西班牙文、法文及德文以詞數計算，所有格與連字詞各視為一詞。

預估速率集中在 `shared/chapter-reading-stats.ts`：繁中每分鐘 300 字、日文 400 字、韓文 250 詞、英文 225 詞、西班牙文與法文 220 詞、德文 200 詞；結果向上取整且最少顯示一分鐘。修改公式後應執行 `pnpm test`，並以 `scripts/verify-chapter-stats.ts` 驗證所有 91 個篇章的 SSR 輸出。

## 選篇與個人閱讀速度

總覽及繁中目錄可按原篇次或「短篇優先」排列，並以 1、2、3、5、10 分鐘為上限篩選。排序與篩選都使用當前語言的正文／譯文統計；若該語言已有個人速度，篩選結果會同步採用個人化分鐘數。

使用者可在篇章頁啟動計時並於讀畢後完成校準。少於 20 秒的樣本不採計，觀察值會限制在該語預設速度的 0.25–3 倍，並以最多 30 次樣本的移動平均降低偶發誤差。各語速度分開保存於瀏覽器 `localStorage` 的 `sunzi:reading-preferences:v1`，不需登入、不傳送至伺服器，可隨時恢復該語預設值。
